## 맛.zip
<맛.zip>은 유튜브 Shorts를 통해 맛집 영상을 즐겨보는 사람들과 맛집을 찾고자 하는 사람들에게 편의를 제공하는 서비스입니다. 맛집 영상에 좋아요를 누르면 자동으로 지도에 북마크를 등록하고 북마크로 등록된 맛집을 기준으로 사용자의 취향에 맞는 맛집을 추천합니다.
